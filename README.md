##  🤖 AI-Powered Research Paper Review and Summarization System

## 📌 About the Project

The AI-Powered Research Paper Review and Summarization System is an intelligent application developed to automate the process of searching, analyzing, reviewing, and summarizing academic research papers.

The system uses Artificial Intelligence (AI), Natural Language Processing (NLP), and Large Language Models (LLMs) to extract important information from research papers, compare findings from multiple articles, generate structured research content, and provide automated review and revision suggestions.

It helps researchers and students reduce manual effort and improve the efficiency of academic literature review.

## 🎯 Project Objectives

- Automate academic research paper searching.
- Extract important information from PDF research papers.
- Analyze and summarize academic documents.
- Compare research findings across multiple papers.
- Generate structured research content automatically.
- Provide AI-based review and revision suggestions.
- Generate references using APA formatting.

## ✨ Key Features

- Automated Paper Search: Search academic research papers using Semantic Scholar API.
- PDF Text Extraction: Extract text and important sections from research documents.
- Information Extraction: Identify key findings, research methods, and important details.
- Cross-Paper Comparison: Compare research findings from multiple papers.
- AI-Based Summarization: Generate meaningful research summaries using LLMs.
- Structured Content Generation: Generate Abstract, Methods, and Results sections.
- Automated Review: Analyze generated content and provide improvement suggestions.
- Revision Workflow: Refine generated research content based on review feedback.
- APA References: Format academic references according to APA style.

## 🚀 Installation and Setup

Step 1: Clone the Repository

git clone https://github.com/sandhiya-vasi/AI-System-to-Automatically-Review-and-Summarize-Research-Papers2.git

Step 2: Navigate to Project Folder

cd AI-System-to-Automatically-Review-and-Summarize-Research-Papers2

Step 3: Create Virtual Environment

python -m venv venv

Step 4: Activate Virtual Environment

Windows:

venv\Scripts\activate

Step 5: Install Required Dependencies

pip install -r requirements.txt

Step 6: Configure API Keys

Create a ".env" file in the project directory.

OPENAI_API_KEY=your_openai_api_key
SEMANTIC_SCHOLAR_API_KEY=your_semantic_scholar_api_key

Add only the API keys required by your implementation. Never upload your actual API keys to GitHub.

Step 7: Run the Application

python app.py

Replace "app.py" with your actual Python entry-point filename if different.
